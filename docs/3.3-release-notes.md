# 随机指令工作台 3.3.0：技能检定增强

## 功能

- **全局技能难度（当前聊天）**：简单／普通／较难／困难／极难，以 d20 为基准的 DC 偏移依次为 −2／0／+2／+4／+6。d10 对应 −1／0／+1／+2／+3，d100 对应 −10／0／+10／+20／+30。插件在本地对 AI 提供的原始 DC 进行一次性调整。结果保存原始 DC、难度偏移和最终 DC；重新生成使用原快照，不重复偏移。
- **大成功／大失败**：默认开启。自然 1 强制大失败，自然最大点强制大成功，优先于普通 DC 比较；关闭时沿用过去的普通数值规则。结果保存数值判定、最终成败和自然极值状态。旧历史检定不会被重新解释。
- **技能使用统计**：各技能的投骰数、已采用数、已采用成功率、最长连败、当前连败。只有明确属于该批检定且经 AI 回报的“采用检定”才计入成功率与连败；未执行、延后、叙事结算及无法确认的不计入。使用次数统计实际唯一骰点批次。
- **分支和恢复**：采用记录按 AI 回复的 swipe 保存，统计从当前可见聊天分支重建。切换 swipe、删除消息、重新生成回复或重复发送事件不造成重复计数。能可靠回读来源的旧 MVU 回报可用于统计，无法确定来源的记录不推测。
- **配置分享**：技能组与 v2 导入导出增加可选字段 `difficulty` 和 `criticalEnabled`，旧文件默认普通难度且开启自然极值。聊天历史、投骰和回报不参与分享。

## 边界与兼容

- AI 仍在常规主聊天回复中选择下轮检定和回报采用情况；难度偏移、极值和统计全部本地计算，无额外模型调用。提示词可能增加少量 token。
- 只有产生新骰点的发送才使用最新难度与极值开关；旧消息及重生成批次保留原始快照。保持技能协议 v2 和旧阈值检定的区分，不将原有 v2 历史误识别为旧协议。
- 未增加成长、熟练度、XP、天赋、资源消耗或额外骰子。
- 自然极值强制成败是新规则，对 d10 的影响比 d100 更明显：大成功与大失败分别为 10% 和 1%。
- AI 回报仍是叙事模型产生的内容，并不等同于插件能独立验证故事事件确实发生；统计严格依赖可明确关联的回报。

## 验证

新增和修订了自动测试，覆盖 d10/d20/d100 的五档 DC 偏移、自然极值覆盖普通判定及关闭恢复、原始 DC 快照、配置导入导出、聊天分支 swipe 切换、重复检定 ID、统计连败、旧 MVU 来源与显式采用记录。CI 运行 `npm test` 和所有运行时 JS 文件的 `node --check`。

> 本次开发不调用真实模型。模型在复杂角色卡中的回报完整性仍受实际提示词遵循程度影响。
