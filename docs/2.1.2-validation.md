# 2.1.2 升级自动刷新验证

日期：2026-11-08。

## 行为

- 使用酒馆原生 `manifest.hooks.update`，导出 `onAutoRandomInputUpdate`。仅升级成功后由宿主触发，同版本补丁也能刷新。
- 每30秒读取本地安装的 `manifest.json`，使用 `cache: no-store`。外部 Git 或文件同步导致的版本变化连续确认两次后触发；不访问 GitHub 检查新版本，不自动下载更新。
- 正在生成、保存聊天、保留输入草稿、编辑消息或打开工作台时暂缓。刷新前保存设置，并回读当前聊天确认消息、技能结果与元数据已经落盘；失败后延迟重试。
- 同一页面只执行一次刷新，使用会话标记防止旧脚本缓存造成循环刷新。首次从没有此功能的旧版升级后，需要手动刷新一次。
