# 随机指令工作台 3.2.2 更新说明

- **手动重新生成**：在「设置 → 自动生成随机指令」开启后，可点击「立即重新生成」，使用当前设置调用故事神谕更新配置。手动生成保留自动周期已累计的 AI 回复楼层；已有请求进行时避免重复触发。
- **剧情记录协议移入提示词**：新发送的剧情记录协议通过酒馆扩展提示词交给模型，不再追加到用户消息正文。群聊、重生成和续写继续恢复对应轮次的协议。
- **随机指令更简洁**：用户消息只展示随机指令内容，不显示候选 ID。插件仍在内部及剧情记录提示词中保留必要关联，以便记录采用情况。
- **兼容与边界**：保留旧消息记录；当其他输入处理器移除或改写已准备的指令块时，不通过隐藏提示词重新添加这些指令。

## 验证

运行项目自动化测试，覆盖手动生成、群聊及重生成、提示词清理、旧记录和输入改写。本次没有进行真实模型调用；实际模型遵守剧情协议的表现未在本次验证。
