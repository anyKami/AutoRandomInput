# 3.1 验证记录

2026-11-11。实测使用独立的 SillyTavern 1.19.0 和故事神谕 2.0.1，配两张合成角色卡、聊天与世界书。模型只收到合成资料。

`npm test`：196 项通过。覆盖首次生成、计数与重生成、群聊楼层、失败和取消、手动与自动请求排队、配置组选择和现有发送、技能检定、导入导出回归。旧升级刷新功能及其专用用例已移除。

| 隔离酒馆实测 | 结果 |
| --- | --- |
| 开启提醒 | 取消后保持关闭，零请求。确认、填写间隔和提示词，再点击开始才发首个请求。 |
| 首次成功 | 自定义提示词和当前卡的世界书进入请求；生成 d1 专用组并选用，手动组和总开关保持原样。 |
| 每两层更新 | 流式和非流式各验证了先到 1/2、第二个新 AI 回复触发一次神谕。限速失败、无正文回复和同层重生成不计数。 |
| 默认生成与覆盖 | 留空后请求使用最新剧情及绑定世界书的启用条目。生成成功后替换同一组的指令，保留 ID 和自定义组名；手动组与历史指令保留。 |
| 隔离与持久化 | 切到第二聊天时默认关闭、选用手动组；返回和刷新恢复第一聊天的进度和专用组，未额外调用。 |
| 发送和导出 | 总开关开启时，主聊天请求带有本轮指令；导出的 JSON v1 包含当前专用组的最新 d1 指令。 |
| 升级不刷新 | 最终版本运行时，关闭工作台、清空输入，再仅修改隔离副本清单的版本号。超过 80 秒后仍是同一页面和聊天，未自动刷新。 |

桌面与 390px 预览验证了取消提醒、取消设置、长提示词、弹窗无横向溢出，以及非法 JSON 只提示一次并保留原配置。可用 `npm run preview` 打开预览：桌面 `/test/preview.html?oracle=1`，手机 `/mobile?oracle=1`。

真实请求按指定顺序使用三个免费模型。0731 Stable 返回 403/503；1017 完成首次生成后遇到限速；Cheap 完成真实回复并触发自动生成，但初版提示让模型多输出了技能组，校验保留了旧配置。修正提示后，Cheap 复验再次限速，改用 `gpt-6-luna` 完成自动覆盖和真实重生成。共 14 次真实请求，其中 5 次为神谕生成；未自动重试。群聊、取消后迟到结果及手动与自动请求并发使用自动化测试覆盖。
